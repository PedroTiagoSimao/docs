---
title: "GET /quotes — List Repair Quotes and Acceptance Status"
sidebarTitle: "List Quotes"
description: "Retrieve repair quotes for your company. Filter by repair ID or quote status, and track when customers accept quotes. Requires quotes:read scope."
---

The quotes endpoint returns repair quotes created in your QUEUE dashboard — including the customer's acceptance timestamp when they've signed off on the quote. Requires the `quotes:read` scope.

```
GET https://<your-queue-domain>/api/v1/quotes
```

## Required Headers

<ParamField header="Authorization" type="string" required>
  Your API token in Bearer format.

  ```
  Authorization: Bearer queue_xxxxxxxxxxxxxxxxxxxxxxxx
  ```
</ParamField>

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for paginated results.
</ParamField>

<ParamField query="per_page" type="integer" default="50">
  Number of results per page. Maximum: `200`. Alias: `limit`.
</ParamField>

<ParamField query="repair_id" type="uuid">
  Return only quotes linked to a specific repair UUID.
</ParamField>

<ParamField query="status" type="string">
  Filter quotes by their current status. Accepts a status UUID, slug, or name (e.g. `accepted`).
</ParamField>

<ParamField query="created_after" type="string">
  Return only quotes created after this timestamp. Must be a valid ISO-8601 datetime string (e.g. `2026-08-01T00:00:00.000Z`).
</ParamField>

<ParamField query="created_before" type="string">
  Return only quotes created before this timestamp. Must be a valid ISO-8601 datetime string (e.g. `2026-08-31T23:59:59.999Z`).
</ParamField>

<ParamField query="sort_by" type="string" default="created_at">
  Field to sort results by. Allowed values: `created_at`, `quote_number`, `status`.
</ParamField>

<ParamField query="sort_dir" type="string" default="desc">
  Sort direction. Allowed values: `asc`, `desc`.
</ParamField>

## Example Requests

```bash
# All quotes for a specific repair
curl 'https://your-domain.com/api/v1/quotes?repair_id=a1b2c3d4-e5f6-7890-abcd-ef1234567890' \
  -H 'Authorization: Bearer queue_xxxxxxxxxxxxxxxxxxxxxxxx'

# Filter by quote status
curl 'https://your-domain.com/api/v1/quotes?status=accepted' \
  -H 'Authorization: Bearer queue_xxxxxxxxxxxxxxxxxxxxxxxx'
```

## Response — 200 OK

<ResponseField name="ok" type="boolean">
  Indicates whether the request was successful. Always `true` for `200 OK` responses.
</ResponseField>

<ResponseField name="data" type="array">
  Array of quote objects.

  <Expandable title="Quote object fields">
    <ResponseField name="id" type="string">
      UUID of the quote.
    </ResponseField>

    <ResponseField name="company_id" type="string">
      UUID of the company this quote belongs to.
    </ResponseField>

    <ResponseField name="quote_number" type="integer">
      Sequential quote number assigned at creation.
    </ResponseField>

    <ResponseField name="quote_number_formatted" type="string">
      Zero-padded display string for the quote number (e.g. `Q-0042`).
    </ResponseField>

    <ResponseField name="status" type="string">
      UUID of the quote's current status.
    </ResponseField>

    <ResponseField name="created_at" type="string">
      ISO-8601 timestamp of when this quote was created.
    </ResponseField>

    <ResponseField name="customer_accepted_at" type="string | null">
      ISO-8601 timestamp of when the customer accepted the quote, or `null` if the quote has not yet been accepted.
    </ResponseField>

    <ResponseField name="repair_id" type="string">
      UUID of the parent repair this quote is linked to.
    </ResponseField>

    <ResponseField name="repair" type="object">
      Summary of the parent repair, including customer details.

      <Expandable title="Repair fields">
        <ResponseField name="id" type="string">
          UUID of the repair.
        </ResponseField>

        <ResponseField name="repair_number" type="integer">
          Sequential repair number.
        </ResponseField>

        <ResponseField name="repair_number_formatted" type="string">
          Zero-padded display string (e.g. `R-0123`).
        </ResponseField>

        <ResponseField name="device" type="string">
          Device name associated with the repair (e.g. `iPhone 13 Pro`).
        </ResponseField>

        <ResponseField name="service" type="string">
          Service type for the repair (e.g. `Screen replacement`).
        </ResponseField>

        <ResponseField name="customer_id" type="string">
          UUID of the customer linked to this repair.
        </ResponseField>

        <ResponseField name="customer" type="object">
          Basic details of the customer linked to this repair.

          <Expandable title="Customer fields">
            <ResponseField name="id" type="string">
              UUID of the customer.
            </ResponseField>

            <ResponseField name="full_name" type="string">
              Full name of the customer.
            </ResponseField>

            <ResponseField name="email" type="string">
              Email address of the customer.
            </ResponseField>
          </Expandable>
        </ResponseField>
      </Expandable>
    </ResponseField>

    <ResponseField name="user_id" type="string">

    </ResponseField>

        <ResponseField name="id" type="string">
          UUID of the technician.
        </ResponseField>

        <ResponseField name="full_name" type="string">
          Full name of the technician.
        </ResponseField>
      </Expandable>
    </ResponseField>
  </Expandable>
