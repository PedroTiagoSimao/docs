title: "List Email Communications for Repairs — QUEUE REST API"
sidebarTitle: "List Communications"
description: "Retrieve email communications linked to repair orders. Filter by repair ID or date range, search by subject or body. Requires communications:read scope."
---

The communications endpoint returns email messages associated with your repair orders — both messages sent to customers and replies received from them. Requires the `communications:read` scope.

```
GET https://<your-queue-domain>/api/v1/communications
```

## Required Headers

<ParamField header="Authorization" type="string" required>
  Bearer token using your QUEUE API key. Format: `Bearer queue_xxxxxxxxxxxxxxxxxxxxxxxx`
</ParamField>

---

## Query Parameters

<ParamField query="page" type="integer" default="1">
  Page number for paginated results.
</ParamField>

<ParamField query="per_page" type="integer" default="50">
  Number of results per page. Maximum value is `200`. Alias: `limit`
</ParamField>

<ParamField query="repair_id" type="uuid">
  Filter to only return messages belonging to a specific repair. Optional.
</ParamField>

<ParamField query="created_after" type="string">
  Return only messages created on or after this timestamp. Accepts ISO-8601 format (e.g. `2026-08-01T00:00:00Z`). Optional.
</ParamField>

<ParamField query="created_before" type="string">
  Return only messages created on or before this timestamp. Accepts ISO-8601 format (e.g. `2026-08-31T23:59:59Z`). Optional.
</ParamField>

<ParamField query="q" type="string">
  Search across `subject`, message body, `from_email`, and `to_email` fields. Alias: `search`. Optional.
</ParamField>

<ParamField query="sort_by" type="string" default="created_at">
  Field to sort results by. Allowed values: `created_at`, `id`.
</ParamField>

<ParamField query="sort_dir" type="string" default="desc">
  Sort direction. Allowed values: `asc`, `desc`.
</ParamField>

---

## Example Requests

```bash
# All messages for a repair
curl 'https://your-domain.com/api/v1/communications?repair_id=a1b2c3d4-e5f6-7890-abcd-ef1234567890' \
  -H 'Authorization: Bearer queue_xxxxxxxxxxxxxxxxxxxxxxxx'

# Search message content
curl 'https://your-domain.com/api/v1/communications?q=ready+for+pickup' \
  -H 'Authorization: Bearer queue_xxxxxxxxxxxxxxxxxxxxxxxx'

# Messages from the last 7 days
curl 'https://your-domain.com/api/v1/communications?created_after=2026-08-12T00:00:00Z' \
  -H 'Authorization: Bearer queue_xxxxxxxxxxxxxxxxxxxxxxxx'
```

## Message Direction

The `direction` field indicates which party initiated the message:

| Value | Description |
|---|---|
| `sent` | A message sent from your shop to the customer, dispatched via the QUEUE platform. |
| `received` | A customer reply received into QUEUE in response to a previous outbound message. |

<Info>
  `description` contains the plaintext email body. HTML formatting is not included.
</Info>
