QUEUE is a repair shop management platform with a public REST API that lets you integrate your existing tools and workflows. Whether you're syncing with a point-of-sale system, pulling repair data into a CRM, or building a custom dashboard, the QUEUE API gives you direct access to your repair orders, customer records, quotes, attachments, and message history.

## How It Works

<Steps>
  <Step title="Generate an API token">
    Log in to your QUEUE dashboard as a company admin. Go to **Profile → API Keys** and create a new token. Save it immediately — it's shown only once.
  </Step>
  <Step title="Authenticate your requests">
    Pass your token in the `Authorization` header on every request:
    ```
    Authorization: Bearer queue_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
    ```
  </Step>
  <Step title="Call the API">
    Use the base URL `https://<your-queue-domain>/api/v1` and send JSON requests. Every response follows a consistent `{ ok, data, meta }` envelope.
  </Step>
  <Step title="Handle responses">
    Check the `ok` field to confirm success. On errors, read `error.code` and `error.details` for actionable feedback.
  </Step>
</Steps>

## Available Endpoints

| Endpoint | Method | Scope Required |
|----------|--------|---------------|
| `/repairs` | `POST` | `repairs:write` |
| `/repairs` | `GET` | `repairs:read` |
| `/procedures` | `GET` | `procedures:read` |
| `/quotes` | `GET` | `quotes:read` |
| `/attachments` | `GET` | `attachments:read` |
| `/communications` | `GET` | `communications:read` |
